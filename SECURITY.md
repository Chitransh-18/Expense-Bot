# Security Policy 🛡️

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of **ExpenseTracker Pro** very seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please send an email directly to the project maintainers with details about the vulnerability.

### What to Include in Your Report
- Type of vulnerability (e.g. JWT secret leak, SQL injection, XSS, CSRF).
- Step-by-step instructions or proof-of-concept to reproduce.
- Impact and recommended fix.

We will acknowledge your report within 48 hours and work with you to release a security patch promptly.
